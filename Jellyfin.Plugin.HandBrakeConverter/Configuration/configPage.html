The conversion settings every library uses unless it has its own, and the starting point for Manual convert. Choose quality, audio, subtitles, file format and what happens to the original.
Rules for looking after your original files: what to check before and after a conversion, and how long replaced originals are kept so you can undo them. Whether a library keeps or replaces its originals is chosen in Default settings (or a library's own settings) under "Original file".

1. Before converting

0 = convert files of any size. Handy for ignoring tiny clips and samples.
A conversion only starts if the disk has room for the new file plus this much spare. Otherwise it waits.

2. After converting: checks before anything is replaced

A converted file that fails a check is thrown away and the original is left exactly as it was.
Skipped for manual conversions that keep the original or burn in subtitles, since those are deliberate.
Example: 20 means a 10 GB original is only replaced if the result is 8 GB or less. A result that saves less is discarded and the original kept. 0 = any saving is enough.
Compares the length, audio tracks, subtitle tracks, chapters and (when kept) HDR with the original, and throws the result away if anything is missing. Uses the ffprobe that comes with Jellyfin.

3. Replaced originals

When a library is set to Replace original, the old file is moved (not copied) into a hidden folder instead of being deleted, so you can undo a bad conversion. By default that folder is .hb-originals inside the same library folder, on the same drive as the video: the move is instant and writes nothing to your system disk, and Jellyfin skips the folder.
After this many days they are deleted automatically. 0 = delete right away (no undo).
Blank = the automatic hidden folder described above (recommended). If you set your own, pick a folder on the same drive as your videos, outside your libraries; on a different drive every original is copied across, which is slow and wears that drive.

Currently on hold

Restore puts the original back next to the converted file as "Name - Original", which Jellyfin shows as a second version.

While converting

How conversions behave while they are running, so they don't get in the way of watching.
The conversion freezes while anyone is playing something in Jellyfin and carries on when they stop. A file is never swapped while someone is watching that exact title.
Normally a paused video doesn't stop a conversion. Turn this on if it should.
Listening to music won't pause conversions, because it uses very little server power.
Gives other programs on the server (including Jellyfin streaming) first call on the CPU, so the server stays responsive. Conversions take a little longer when the server is busy. Recommended.
